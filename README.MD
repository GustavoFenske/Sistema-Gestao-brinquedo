# Sistema de Gestão de Brinquedos - CRUD PHP

Trabalho de recuperação para gestão de cadastro de brinquedos utilizando PHP com MySQL.

## 📁 Estrutura de Arquivos
- `DB/database.sql`: Script de criação da base de dados e tabela.
- `infra/conexao.php`: Conexão com o banco de dados.
- `public/cadastrar.php`: Formulário de criação de brinquedo.
- `public/editar.php`: Formulário de edição de brinquedo.
- `index.php`: Listagem e remoção de brinquedos.

## 🚀 Como Executar
1. Copie a pasta do projeto para o diretório `htdocs` do XAMPP/WAMP.
2. Importe o arquivo `DB/database.sql` no phpMyAdmin.
3. Abra no navegador: `http://localhost/nome_da_sua_pasta/index.php`.
